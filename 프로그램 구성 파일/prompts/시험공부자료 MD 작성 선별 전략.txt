# 시험공부자료 MD 작성 선별 전략

이 문서는 문제를 많이 만드는 규칙이 아니라, 실제 시험에서 점수를 올릴 가능성이 높은 문항만 고르는 규칙이다. 새 과목에서 경로 하나만 주어져도 아래 순서로 자료의 강도를 판단한다.

## 1. 최신 완성본에서 확인한 패턴

- `예방약학_기말고사_문제.md`: 실제 기출 PDF가 가장 강한 신호였다. 2023년/2025년 기출 문항을 앞에 두고, 흐리거나 빈 선지는 수업자료로 복원했다. 객관식/OX 형태를 단답형으로 바꾸지 않고, 답안 영역에서 O/X 리뷰와 틀린 보기 정정을 제공했다.
- `바이오의약품학_기말고사_문제.md`: 기출보다 55쪽 요약자료가 실질적 선별 축이었다. 억지 객관식을 만들지 않고, 정의·비교·절차·기전 중심의 서술형 카드 41개로 압축했다. 직접 답안 뒤에 `[해설]`을 붙여 용어 정의와 맥락을 쉽게 설명했다.
- `의약화학_기말고사_문제.md`: `기출문제 공지.txt`가 문항 수와 유형을 강하게 정했다. 공지가 말한 객관식/서술형 배분, 제외 범위, “구조 직접 매칭은 안 나옴” 같은 조건을 반영했고, 예상문제 PDF와 수업자료 페이지를 연결해 31문항으로 정리했다. 객관식 정답 O 항목은 반복 설명을 줄이고, X 항목은 `원문 -> 정정 사실`로 고쳤다.

이 숫자는 새 과목에 하드코딩하지 않는다. 핵심은 자료가 강하게 말하는 범위와 시험형에 맞춰 문제 수와 형태를 정하는 것이다.

## 2. 자료 우선순위

1. 시험 공지, 기출문제 공지, 시험범위 안내, 교수 코멘트
   - 문항 수, 객관식/서술형 비율, 제외 범위, 꼭 보라는 페이지, 외울 필요 없는 내용을 결정한다.
   - 공지에서 제외한 구조-이름 매칭, 단순 분류, 특정 장은 수업자료에 있어도 낮춘다.

2. 실제 기출, 족보, 복원 문제, 예상문제와 풀이
   - 이미 문제 형태인 자료는 가장 먼저 복원한다.
   - 객관식, O/X, 빈칸, 연결형, 표 문제는 원래 형태를 유지한다.
   - 풀이가 붙어 있으면 정답 근거와 함정 포인트를 함께 뽑되, 최종 답안은 앱에서 외우기 쉬운 짧은 줄로 정리한다.

3. 정리자료, 요약자료, 5분 문답, 학생/교수 요약 PDF
   - 전체 수업자료보다 선별된 자료가 있으면 먼저 본다.
   - 요약자료가 시험범위 전체를 촘촘히 덮으면 그 자료를 backbone으로 삼고, 수업자료는 출처 이미지와 빠진 근거 보강에 쓴다.
   - 요약자료가 4쪽처럼 너무 압축되어 있으면 큰 목차와 핵심어만 잡고 원본 수업자료로 검증한다.

4. 수업자료 PDF/PPT
   - 텍스트 추출만으로 전부 훑지 않는다. 먼저 위 자료들이 찍어 준 장, 페이지, 주제부터 본다.
   - 빨간색, 형광색, 굵게, 밑줄, 박스, 별표, 화살표, 비교표, 도식 중심부, 반복 등장, 큰 글씨를 높은 후보로 본다.
   - 배경 설명, 역사, 단순 예시, 공지가 낮춘 범위는 후순위다.

5. 경로 밖 레퍼런스
   - 같은 과목의 이전 시험 폴더는 스타일과 문제 깊이 참고용이다.
   - 현재 문제의 정답 근거와 `출처:`에는 절대 쓰지 않는다.

## 3. 과목 유형별 생성 방식

- 기출 중심 과목: 기출 원문 복원 단계가 먼저다. 복원 뒤에 기출과 겹치는 수업자료 내용을 추가 예상문제로 보강한다.
- 공지 중심 과목: 공지의 장별 문항 수와 유형을 단계명으로 삼는다. 공지에서 “안 나옴”, “외울 필요 없음”, “객관식 쉬움”, “서술형”이라고 한 내용을 그대로 반영한다.
- 요약자료 중심 과목: 요약자료의 페이지 흐름을 따라 정의, 분류 기준, 비교, 절차, 기전, 한계와 해결 전략을 묻는다. 보기형보다 단답/짧은 서술형이 자연스러우면 그 형식을 쓴다.
- 수업자료만 있는 과목: 목차와 강조 페이지를 먼저 뽑고, 단원별로 작은 목표를 세운 뒤 문제를 만든다. 처음부터 전체 페이지를 균등 배분하지 않는다.

## 4. 문제 선별 기준

높게 본다:
- 기출과 수업자료가 겹치는 내용
- 공지에서 직접 언급한 장, 문제 유형, 페이지, 약물군, 기전, SAR, 비교 축
- 요약자료에서 한 페이지에 압축된 정의·분류·절차·기전
- 표/비교표/계산표처럼 문제로 바꾸기 쉬운 암기 단위
- 틀린 보기로 만들기 좋은 방향성, 예외, 짝짓기, 증가/감소, reversible/irreversible 같은 대비

낮게 본다:
- 시험 공지가 제외한 범위
- 단순 배경지식, 역사, 이름 나열, 구조-이름 매칭만 묻는 항목
- 출처 이미지 없이 일반지식으로만 답해야 하는 내용
- 이미 만든 문항과 같은 답을 요구하는 중복 문항
- 문제 제목이나 보기 순서만 보고 답이 보이는 문항

## 5. 후처리 규칙

- 초안이 너무 많으면 기출·공지·요약자료와 겹치지 않는 주변 설명부터 삭제한다.
- 객관식 O 항목 설명은 반복이면 지운다. 함정, 분류, 예외를 이해해야 할 때만 `[보기해설]`에 `// 짧은 이유`를 붙인다.
- X 항목은 반드시 원래 틀린 문장 뒤에 `-> 정정 사실`을 먼저 쓴다.
- 서술형은 답을 먼저 쓰고, 이해가 필요한 경우 `[배경설명]` 또는 기존 호환용 `[해설]`에서 용어 정의, 전후 맥락, 왜 답이 되는지 순서로 설명한다.
- `[배경설명]`, `[보기해설]`, `[해설]`은 표준 라벨로 허용한다. `핵심:`, `요약:`, `암기포인트:` 같은 임의 라벨은 쓰지 않는다.
- 최종 검토 때 최신 완성본 3개를 열어 과목 성격이 비슷한 파일과 비교한다. 문제 수, 문제형, 답안 길이, O/X 리뷰 방식이 과목 성격에 맞는지 본다.
