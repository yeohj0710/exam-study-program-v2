시험 자료 암기 프로그램 사용설명서

비개발자가 내려받은 뒤 더블클릭으로 실행해서 PDF 문제 자료를 카드처럼 복습하는 용도입니다.

1. 실행

  1. 폴더를 열고 시험 자료 암기 프로그램.exe를 더블클릭합니다.
  2. 검은 로그 창 없이 브라우저가 자동으로 열립니다.
  3. 이미 실행 중이면 새 서버를 만들지 않고 기존 프로그램 주소를 다시 엽니다.
  4. 완전히 끌 때는 화면 오른쪽 위의 종료 버튼을 누릅니다.
exe가 회사나 학교 보안 정책 때문에 막히면 시험 자료 암기 프로그램.cmd를 더블클릭하세요. 이 보조 실행 파일은 콘솔 창이 보일 수 있습니다.

2. 자료 가져오기

처음 실행했을 때 자료가 없으면 PDF 폴더와 기존 캡처 폴더 입력칸이 보입니다. 경로가 맞으면 자료 가져오기를 누릅니다.

입력칸 기본 경로
PDF 폴더 G:\내 드라이브\여형준님\21 6-1
기존 캡처 폴더 G:\내 드라이브\여형준님\21 6-1\족보 암기 프로그램\중간고사

PDF를 넣으면 프로그램이 텍스트를 읽고 문제 카드, 원문 페이지 이미지, 문제 영역 crop 이미지를 자동 생성합니다. 중간고사 정리자료 구조가 없으면 지정한 폴더 안의 일반 PDF를 문제셋으로 가져옵니다. 텍스트가 안 뽑히는 스캔 PDF는 전체 페이지 검수 카드로 남습니다.

3. 학습 화면

  • 왼쪽 문제셋에서 과목이나 자료 묶음을 고릅니다.
  • 왼쪽 패널의 접기 버튼으로 문제셋을 접고, 닫힌 뒤에는 왼쪽 문제셋 탭으로 다시 펼칩니다.
  • 상단의 남은 카드, 다시 볼 카드, 신규, 검수, 보류 버튼으로 볼 범위를 바꿉니다.
  • 정답 보기(J)를 누르면 정답과 원문 crop이 보입니다.
  • 건너뛰기(K)는 기록 없이 다음 카드로 넘깁니다. 카드는 목록에 그대로 남습니다.
  • 외움·제외(1)를 누르면 외운 카드로 처리되어 기본 학습 목록에서 빠집니다.
  • 종료를 누르면 백그라운드 서버까지 같이 종료됩니다.

4. 목록과 검수

  • 목록(L)을 누르면 현재 문제셋의 카드가 한눈에 보입니다. 원하는 문제를 클릭하면 바로 이동합니다.
  • 검수(I)를 누르면 오른쪽 검수 패널이 열립니다.
  • 검수 패널에서는 누락 이미지, 원본 근거, 자동 추출 신뢰도, 카드 앞면/뒷면 편집을 확인할 수 있습니다.

5. 데이터 위치

원본 PDF와 캡처 자료는 읽기만 합니다. 프로그램이 만든 데이터는 아래 폴더에 저장됩니다.

프로그램 구성 파일\data

이 폴더에는 카드 라이브러리, 복습 기록, 검수 기록, 자동 생성된 이미지가 들어갑니다.

6. 자주 생기는 문제

증상 확인할 것
브라우저가 안 열림 실행 창에 표시된 http://127.0.0.1:포트번호 주소를 직접 브라우저 주소창에 붙여 넣습니다.
자료가 안 만들어짐 PDF 폴더 경로가 맞는지, PDF 파일이 실제로 들어 있는지 확인합니다.
이미지가 안 보임 검수 패널의 무결성 항목에서 누락 이미지 수를 확인한 뒤 자료를 다시 가져옵니다.
이전 순서가 바뀐 것 같음 브라우저 저장소에 선택 문제셋, 필터, 섞은 순서, 현재 위치가 저장됩니다. 같은 브라우저에서 다시 열면 이어집니다.
