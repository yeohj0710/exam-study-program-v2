Exam Study Program 사용설명서

Markdown 문제 데이터로 시험 문항을 섞어서 암기하는 로컬 프로그램입니다.

1. 실행

  1. 시험 자료 암기 프로그램.exe를 실행합니다.
  2. 종료할 때는 왼쪽 아래 전원 버튼을 누르고 확인합니다.
  3. 전체화면은 브라우저 기본 단축키 F11을 사용합니다.

2. 데이터 위치

C:\dev\exam-study-program\문제 데이터

이 폴더의 .md 파일이 문제 세트입니다. 파일명이 과목명처럼 표시됩니다.

3. Markdown 형식

# 문제

실제 문제 텍스트를 바로 적습니다.

- 보기 A
  여러 줄 보기도 가능합니다.
  ![그림 설명](assets/과목명/example.png)

- 보기 B

답: **정답 내용**
출처: 강의자료.pdf p.12
![정답 그림](assets/과목명/answer.png)
  • 문항은 # 문제 구분선으로 시작하고, 실제 문제 텍스트는 그 아래에 바로 씁니다.
  • 답을 유추하게 만드는 문제 제목은 쓰지 않습니다.
  • 보기는 없어도 되고, 필요할 때만 - 보기로 씁니다.
  • 보기 다음 줄들은 다음 - 보기 전까지 같은 보기로 묶입니다.
  • 답은 답: 또는 정답:으로 시작합니다.
  • 답안의 핵심 단어는 **굵게**로 표시할 수 있고, 답안 영역에서는 강조색으로 보입니다.
  • 가능하면 답안에 출처:를 함께 적습니다.
  • 그림 이름은 화면에 표시되지 않고 툴팁으로만 남습니다.

4. 조작

  • J 또는 Space: 정답 보기/숨기기
  • K 또는 →: 다음 문제
  • 1: 암기 완료
  • R: 암기 완료 복구
  • Ctrl+B: 문제 데이터 패널
  • Ctrl+E: Markdown 편집 패널
  • Ctrl+I: 검증 패널
  • Ctrl+-, Ctrl+=, Ctrl+0: 글자 크기 조절/초기화
  • Alt+[, Alt+]: 다크모드 눈부심 조절
