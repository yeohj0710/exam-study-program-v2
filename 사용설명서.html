Exam Study Program 사용설명서

시험 자료를 문제 데이터로 바꾸고, 로컬 화면에서 정답을 가리며 반복 암기하는 프로그램입니다.

시연 영상

처음 쓰는 경우에는 아래 시연 영상을 먼저 보면 실행, 문제 데이터 선택, 정답 확인, PDF 내보내기 흐름을 한 번에 이해할 수 있습니다.

YouTube에서 시연 영상 열기

1. 실행

  1. 시험 자료 암기 프로그램.exe를 더블클릭합니다.
  2. 브라우저에 Exam Study 화면이 열리면 왼쪽 목록에서 공부할 문제 세트를 고릅니다.
  3. 공부를 끝낼 때는 열린 Exam Study 브라우저 창을 닫습니다.

exe가 막히면 시험 자료 암기 프로그램.cmd를 실행합니다.

2. 문제 데이터 만들기

문제 양식은 사람이 외울 필요가 없습니다. 문제 데이터 작성 프롬프트.txt를 로컬 PC에서 파일을 읽을 수 있는 AI에 넣고, 마지막에 시험 자료 폴더 경로만 붙이면 됩니다.

  1. 문제 데이터 작성 프롬프트.txt를 엽니다.
  2. 파일 내용을 전부 복사해서 Codex, Claude Code 같은 로컬 작업 가능한 AI에 붙여넣습니다.
  3. 프롬프트 맨 마지막 시험범위 자료 경로: 아래에 자료 폴더 경로만 붙여넣습니다.
시험범위 자료 경로:
G:\내 드라이브\과목명\기말고사 범위 자료

AI가 과목명, 시험명, 저장 위치, 문제 수를 스스로 판단합니다. 결과 Markdown은 문제 데이터 폴더에, 이미지는 문제 데이터\assets 아래에 저장됩니다.

새 문제 데이터를 만든 뒤에는 앱에서 F5를 누르거나 새로고침 버튼을 눌러 다시 읽습니다.

3. 더 좋은 문제를 뽑는 팁

기출이 제일 중요

기출, 복원 문제, 족보, 예상문제가 있으면 자료 폴더에 같이 넣습니다. 문제 유형과 함정까지 가장 잘 알려 줍니다.

시험 유형을 알려주기

단답형, O/X, 객관식, 빈칸, 짧은 서술형, 계산 문제처럼 실제 시험 형식을 구체적으로 적으면 좋습니다.

출제자 힌트 넣기

교수님이 강조한 말, 빨간 글씨, 별표, 반복 설명, 비교표, 예외 조건처럼 시험에 가까운 힌트를 적습니다.

좋은 레퍼런스 주기

이전에 잘 만든 정리자료나 문제 세트가 있으면 참고용으로 알려줍니다. 현재 문제의 출처는 현재 시험범위 자료 안에서만 잡습니다.

4. 공부 조작

  • J 또는 Space: 정답 보기/숨기기
  • K 또는 →: 다음 문제
  • 1: 암기 완료로 넘기기
  • R: 암기 완료 복구
  • S: 문제 순서 섞기
  • L: 문제 번호 목록 열기
  • /: 문제 데이터 검색
  • P: 전체 문답 PDF 내보내기
  • F5: 문제 데이터 다시 읽기
  • F11: 브라우저 전체화면

5. 패널과 편집

  • Ctrl+B: 문제 데이터 패널 열기/닫기
  • Ctrl+E: Markdown 편집 패널 열기/닫기
  • Ctrl+I: 검증 패널 열기/닫기
  • Ctrl+-, Ctrl+=, Ctrl+0: 글자 크기 조절/초기화
  • 다크모드에서 Alt+[, Alt+]: 화면 밝기 조절

Markdown 편집 패널에서는 현재 문제 데이터를 바로 수정하고 저장할 수 있습니다. 검증 패널은 빠진 답, 깨진 이미지, 형식 문제를 보여줍니다.

6. PDF 내보내기

문답 PDF: 문제, 답, 출처, 출처 이미지를 포함한 자세한 PDF입니다.

5분 문답 PDF: 시험 직전 훑기용으로 문제와 핵심 답만 모은 짧은 PDF입니다.
