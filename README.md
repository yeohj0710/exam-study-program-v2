# Exam Study Program

시험 직전에 빠르게 외우기 위한 로컬 문제 암기 프로그램입니다. 개발 지식 없이 `시험 자료 암기 프로그램.exe`를 실행해서 씁니다.

## 시연 영상

처음 쓰는 경우에는 아래 시연 영상을 먼저 보면 실행, 문제 데이터 선택, 정답 확인, PDF 내보내기 흐름을 한 번에 이해할 수 있습니다.

[Exam Study Program 시연 영상 보기](https://www.youtube.com/watch?v=2bAfXyoOpfo)

## 1. 실행

1. 루트 폴더의 `시험 자료 암기 프로그램.exe`를 더블클릭합니다.
2. 브라우저에 Exam Study 화면이 열리면 왼쪽 `문제 데이터` 목록에서 공부할 세트를 고릅니다.
3. 공부를 끝낼 때는 열린 Exam Study 브라우저 창을 닫습니다.

exe가 막히면 `시험 자료 암기 프로그램.cmd`를 실행합니다.

## 2. 문제 데이터 만들기

문제 데이터는 사람이 직접 형식을 외워서 쓰는 방식이 아닙니다. 로컬 PC에서 파일을 읽을 수 있는 AI에게 프롬프트와 자료 폴더를 주면 됩니다.

1. `문제 데이터 작성 프롬프트.txt`를 엽니다.
2. 내용을 전부 복사해서 Codex, Claude Code 같은 로컬 작업 가능한 AI에 붙여넣습니다.
3. 프롬프트 맨 마지막 `시험범위 자료 경로:` 아래에 시험 자료가 들어 있는 폴더 경로만 붙여넣습니다.

예:

```text
시험범위 자료 경로:
G:\내 드라이브\과목명\기말고사 범위 자료
```

AI가 자료를 읽고 과목명, 시험명, 저장 위치, 필요한 문제 수를 스스로 판단해서 `문제 데이터` 폴더에 Markdown 문제 파일을 만듭니다. 이미지는 `문제 데이터\assets` 아래에 같이 저장됩니다.

새 파일을 만들었거나 수정했으면 앱에서 `F5`를 누르거나 새로고침 버튼을 눌러 문제 데이터를 다시 읽습니다.

## 3. 더 좋은 문제를 뽑는 팁

AI에게 자료 폴더만 줘도 작동하지만, 아래 힌트가 있으면 품질이 훨씬 좋아집니다.

- 예전 기출, 복원 문제, 족보, 예상문제가 있으면 자료 폴더 안에 같이 넣습니다. 가장 좋은 힌트입니다.
- 시험 유형을 알려줍니다. 예: 단답형, O/X, 객관식, 빈칸, 짧은 서술형, 계산 문제.
- 교수님이나 출제자가 중요하다고 한 포인트를 구체적으로 적습니다. 예: 빨간 글씨, 별표, 반복 설명, 비교표, 수업 중 강조한 예외.
- 이전에 잘 만든 정리자료나 문제 세트가 있으면 참고용으로 같이 알려줍니다. 단, 현재 시험 문제의 `출처:`는 현재 시험범위 폴더 안 자료여야 합니다.
- 애매하게 많이 만들라고 하기보다 “실제 시험에 나올 가능성이 높은 것만” 만들게 하는 편이 좋습니다.

## 4. 공부 화면 조작

- `J` 또는 `Space`: 정답 보기/숨기기
- `K` 또는 `→`: 다음 문제
- `1`: 암기 완료로 넘기기
- `R`: 암기 완료 복구
- `S`: 문제 순서 섞기
- `L`: 문제 번호 목록 열기
- `/`: 문제 데이터 검색
- `P`: 전체 문답 PDF 내보내기
- `F5`: 문제 데이터 다시 읽기
- `F11`: 브라우저 전체화면

## 5. 패널과 편집

- `Ctrl+B`: 왼쪽 문제 데이터 패널 열기/닫기
- `Ctrl+E`: Markdown 편집 패널 열기/닫기
- `Ctrl+I`: 검증 패널 열기/닫기
- `Ctrl+-`, `Ctrl+=`, `Ctrl+0`: 글자 크기 조절/초기화
- 다크모드에서 `Alt+[`, `Alt+]`: 화면 밝기 조절

Markdown 편집 패널에서는 현재 문제 데이터를 바로 수정하고 저장할 수 있습니다. 검증 패널은 빠진 답, 깨진 이미지, 형식 문제 같은 오류를 보여줍니다.

## 6. PDF 내보내기

공부 화면 위쪽의 다운로드 버튼으로 PDF를 만들 수 있습니다.

- `문답 PDF`: 문제, 답, 출처, 출처 이미지를 포함한 자세한 PDF
- `5분 문답 PDF`: 시험 직전 훑기용으로 문제와 핵심 답만 모은 짧은 PDF
