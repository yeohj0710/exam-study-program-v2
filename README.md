# Exam Study Program

시험 암기용 로컬 Markdown 학습 프로그램입니다.

## 실행

1. 루트 폴더의 `시험 자료 암기 프로그램.exe`를 실행합니다.
2. 브라우저가 `Exam Study Program`으로 열립니다.
3. 종료는 왼쪽 아래 전원 버튼을 누른 뒤 확인합니다.

exe가 막히면 `시험 자료 암기 프로그램.cmd`를 실행하세요.

## 문제 데이터

모든 문제 데이터는 루트의 `문제 데이터` 폴더에 둡니다.

```text
C:\dev\exam-study-program\문제 데이터
C:\dev\exam-study-program\문제 데이터\assets
```

Markdown 파일명은 과목명 또는 시험명으로 표시됩니다.

## Markdown 형식

```md
# 문제

실제 문제 텍스트를 바로 적습니다.

- 보기 A
  여러 줄 보기도 가능합니다.
  ![그림 설명](assets/과목명/example.png)

- 보기 B

답: **정답 내용**
출처: 강의자료.pdf p.12
![정답 그림](assets/과목명/answer.png)
```

- 한 문제는 `# 문제` 구분선으로 시작합니다. 실제 문제 텍스트는 그 아래에 바로 씁니다.
- 답을 유추하게 만드는 문제 제목은 쓰지 않습니다.
- 보기는 필요할 때만 `- 보기` 형식으로 씁니다. 보기가 없어도 됩니다.
- 보기의 다음 줄들은 다음 `- 보기`가 나오기 전까지 같은 보기로 묶입니다.
- 답은 `답:` 또는 `정답:`으로 시작합니다.
- 답안의 핵심 단어는 `**굵게**`로 표시할 수 있고, 답안 영역에서는 강조색으로 보입니다.
- 가능하면 답안에 `출처:`를 함께 적습니다.
- `### Answer`, `### Note`, 별도 ID 문법은 쓰지 않습니다.
- 이미지는 화면에 이름을 표시하지 않고 툴팁으로만 남깁니다.

## 단축키

- `J` 또는 `Space`: 정답 보기/숨기기
- `K` 또는 `→`: 다음 문제
- `1`: 암기 완료
- `R`: 암기 완료 복구
- `Ctrl+B`: 문제 데이터 패널
- `Ctrl+E`: Markdown 편집 패널
- `Ctrl+I`: 검증 패널
- `Ctrl+-`, `Ctrl+=`, `Ctrl+0`: 글자 크기 조절/초기화
- `Alt+[`, `Alt+]`: 다크모드 눈부심 조절
- `F11`: 브라우저 전체화면
