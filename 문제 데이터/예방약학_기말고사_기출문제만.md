# 문제

리놀레산과 리놀렌산을 동일하게 100g을 부패시켰다. 변질되는 동안 다음 값들에 대한 설명으로 옳지 않은 것은?

값의 의미:
- A: Linoleic acid(18:2)의 요오드가
- B: Linolenic acid(18:3)의 요오드가
- C, D: 각각 Linoleic acid와 Linolenic acid의 산가
- F: Linolenic acid의 과산화물가
- G, I: 각각 Linoleic acid의 카보닐가와 TBA 시험가

- A가 B보다 크다
- C와 D는 시간이 지남에 따라 증가한다
- F는 시간이 지남에 따라 증가하다가 결국에는 감소한다
- 비타민 E를 넣어주면 Linoleic acid의 요오드가는 유지된다
- G와 I는 양의 상관관계를 가진다

답: 아래 표시 보기
O C와 D는 시간이 지남에 따라 증가한다 // 산가는 산패 진행 시 상승하는 지표라 두 지방산 모두 시간이 지나면 증가한다.
O F는 시간이 지남에 따라 증가하다가 결국에는 감소한다 // 과산화물가는 초기 산화에서 증가하지만 이후 carbonyl 화합물로 분해되어 감소한다.
O 비타민 E를 넣어주면 Linoleic acid의 요오드가는 유지된다 // 비타민 E는 산화를 억제해 Linoleic acid의 불포화도 감소를 늦춘다.
O G와 I는 양의 상관관계를 가진다 // carbonyl가와 TBA 시험가는 모두 산패 생성물 증가를 반영해 같이 증가하는 방향이다.
X A가 B보다 크다 -> Linolenic acid(18:3)가 Linoleic acid(18:2)보다 불포화도가 높으므로 **B > A**이다. 요오드가는 불포화도 지표라 18:3인 B가 더 크다.

# 문제

- Vitamin D가 결핍되면 소장에서 칼슘과 인의 흡수가 줄어들고, 신장에서는 칼슘과 인산의 재흡수가 감소하여 결과적으로 골다공증을 유발할 수 있다
- 인의 섭취가 적을 경우, 혈중 칼슘농도는 증가하고 혈중 PTH의 농도는 감소하여 신장에서의 인 배설을 감소시켜 혈중 인농도를 정상으로 유지하고자 한다
- 고인산 식이로 혈중 인농도가 증가하면, 신장에서 칼시트리올의 생성이 증가하여 혈중 인 농도를 감소시킨다
- 혈청중의 Mg 이온은 어느 정도 Ca 이온과 반비례적으로 변동하여 Ca 이온이 증가하면 Mg 이온의 농도는 감소한다

- 우유와 우유 함유음료를 tetracycline과 함께 섭취할 경우 칼슘과 의약품의 결합을 통해 약물의 흡수 효율을 높여준다

인스턴트 식품이나 식품첨가물 등으로 고인산 식이가 지속될 때 일어나는 변화로 가장 알맞은 것은?

- 대변 칼슘 배설 감소
- PTH 증가
- calcitriol 생성 증가
- 신장 인 배설 감소
- 체내 Mg 감소

답: 아래 표시 보기
O PTH 증가 // 고인산 상태에서는 PTH가 올라가 신장 인 배설을 늘리는 방향으로 보상한다.

X calcitriol 생성 증가 -> calcitriol 생성은 **감소**한다. 인 흡수를 더 늘리는 calcitriol을 낮추는 방향으로 조절된다.
X 신장 인 배설 감소 -> 신장 인 배설은 **증가**한다. 혈중 인이 높으면 몸은 신장에서 인을 더 내보낸다.
X 체내 Mg 감소 -> 고인산 식이의 핵심 변화는 **PTH 증가**, 신장 인 배설 증가, calcitriol 감소이다. 이 문항의 조절축은 Mg보다 PTHㆍcalcitriolㆍ인 배설이다.

# 문제

단백질 영양가 판정 지표의 계산식으로 틀린 것을 모두 고르시오.

- 단백질효율(PER) = 체중 증가량 / 단백질 섭취량
- 생물가(BV) = 체내에 보유된 질소량 / 흡수된 질소량
- 화학가(CS) = 체내단백질 잔존량 / 단백질 섭취량
- 단백질가(PS) = 식품 중 제한아미노산의 양 / 달걀 중 해당 제한아미노산의 양
- 정단백질가(NPU) = 흡수된 질소량 / 체내에 보유된 질소량

답: 아래 표시 보기
O 단백질효율(PER) = 체중 증가량 / 단백질 섭취량 // 먹은 단백질이 체중 증가로 얼마나 이어졌는지를 보는 지표이다.
O 생물가(BV) = 체내에 보유된 질소량 / 흡수된 질소량 // 흡수된 질소 중 몸에 남은 비율을 보는 지표이다.
O 단백질가(PS) = 식품 중 제한아미노산의 양 / 달걀 중 해당 제한아미노산의 양 // 기준 단백질인 달걀과 제한아미노산 양을 비교한다.
