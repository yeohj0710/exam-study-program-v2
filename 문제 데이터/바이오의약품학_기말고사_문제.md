# 문제

유전자치료제는 작용기전, 전달체, 투여방식이라는 세 기준으로 분류한다. 각 기준에서 무엇을 묻는 것인지 설명하시오.

답:
작용기전: 유전자를 **어떻게 조작해서** 치료효과를 내는가
전달체: 유전자를 표적 세포까지 **무엇에 실어** 보낼 것인가
투여방식: 몸 안에서 바로 할 것인가, 세포를 꺼내 조작한 뒤 다시 넣을 것인가

[해설]
유전자치료제를 분류할 때는 한 가지 기준만 보는 것이 아니라, 치료가 작동하는 방식과 ==전달 방식==과 투여 방식을 나누어 본다.
==작용기전==은 유전자를 보충하는지, 발현을 억제하는지, 유전체를 편집하는지처럼 치료효과가 생기는 원리를 묻는다.
==전달체==는 ==AAV==, ==Lentivirus==, ==LNP==처럼 유전물질을 세포까지 운반하는 수단을 묻는다.
==투여방식==은 환자 몸 안에 직접 넣는 ==in vivo==인지, 세포를 몸 밖에서 조작한 뒤 다시 넣는 ==ex vivo==인지를 묻는다.

# 문제

Zolgensma, Luxturna, Onpattro, Casgevy를 작용기전 관점에서 나누면 어떻게 정리되는가?

답:
**Zolgensma**, **Luxturna**: 유전자 치환 및 추가
**Onpattro**: 유전자 발현 억제
**Casgevy**: 유전자 편집 및 교정

[해설]
==Zolgensma==와 ==Luxturna==는 부족하거나 결함이 있는 유전자 기능을 정상 유전자 제공으로 보충하는 치료제로 정리된다.
==Onpattro==는 병을 일으키는 단백질이 만들어지지 않도록 유전자 발현을 억제하는 쪽에 해당한다.
==Casgevy==는 유전체의 특정 부분을 편집하거나 교정하는 치료제로 분류된다.
이 문제는 약물명을 외우는 것보다, 각 약물이 **유전자 추가**, **발현 억제**, **유전자 편집** 중 어디에 속하는지 연결하는 것이 중요하다.

# 문제

AAV, Lentivirus/Retrovirus, LNP는 각각 어떤 전달 상황에 적합한가?

답:
**AAV**: 체내에서 장기간 유전자 발현이 필요한 in vivo 유전자치료
**Lentivirus/Retrovirus**: 세포 DNA에 삽입되어 ex vivo 세포·유전자치료제 제조에 사용
**LNP**: mRNA 같은 핵산을 지방질로 감싸 세포 안으로 전달

[해설]
==AAV==는 adeno-associated virus 기반 ==전달체==로, 체내에서 비교적 장기간 유전자 발현이 필요한 ==in vivo== 유전자치료에 자주 연결된다.
==Lentivirus==와 ==Retrovirus==는 유전자가 세포 DNA에 삽입될 수 있어, 환자 세포를 밖에서 조작하는 ==ex vivo== 세포·유전자치료제 제조와 연결된다.
==LNP==는 ==lipid nanoparticle==로, mRNA 같은 핵산을 지방질 입자로 감싸 세포 안으로 전달하는 비바이러스 ==전달체==이다.
따라서 ==AAV==는 체내 장기 발현, ==Lentivirus==와 ==Retrovirus==는 ==ex vivo== 세포 조작, ==LNP==는 mRNA 전달로 구분하면 된다.

# 문제

In vivo 유전자치료와 Ex vivo 유전자치료를 제조 난이도와 안전성 관점에서 비교하시오.

답:
**In vivo**: 치료 유전자를 체내 표적 부위에 직접 주사하므로 간편하지만, 전달체가 다른 장기로 갈 위험이 있다.
**Ex vivo**: 세포를 체외에서 조작한 뒤 다시 넣으므로 원하는 세포만 조작하기 쉽지만, 맞춤형 제조가 비싸고 오래 걸린다.

[해설]
==In vivo== 유전자치료는 치료 유전자를 환자 몸 안에 직접 투여해 목표 조직에서 작동하게 하는 방식이다.
이 방식은 세포를 밖에서 따로 제조하지 않아 간편하지만, ==전달체==가 원하는 조직이 아닌 다른 장기로 갈 수 있어 ==안전성== 문제가 생긴다.
==Ex vivo== 유전자치료는 환자나 공여자의 세포를 몸 밖으로 꺼내 유전자를 조작한 뒤 다시 투여하는 방식이다.
==Ex vivo==는 원하는 세포만 골라 조작할 수 있어 통제가 쉽지만, 맞춤형 제조가 필요해 시간과 비용이 커진다.

# 문제

CAR 면역치료제는 면역세포의 어떤 능력을 어떤 방향으로 바꾸는 기술인가?

답:
면역세포에 종양 항원을 인지하는 **인공 수용체**를 도입한다.
면역세포의 세포독성 기능을 특정 암 표적에 대해 **재지향**한다.

[해설]
==CAR==는 chimeric antigen receptor, 즉 키메릭 ==항원== 수용체이다.
면역세포가 원래 가지고 있던 살상 능력을 암세포 ==표적 항원== 쪽으로 돌려주는 인공 수용체라고 이해하면 된다.
여기서 재지향은 면역세포가 아무 대상이나 공격하는 것이 아니라, ==CAR==가 인식하는 특정 종양 ==항원==을 가진 세포를 공격하도록 방향을 바꾼다는 뜻이다.
따라서 ==CAR== 면역치료제의 핵심은 **면역세포**, **종양 항원 인식**, **세포독성 기능 재지향**이다.

# 문제

CAR 구조가 항원결합부, hinge/spacer, transmembrane domain, 세포내 신호전달부로 나뉜다는 사실이 왜 중요한가?

답:
각 부분을 바꾸면 표적 항원, 활성 강도, 지속성, 안전성을 따로 조절할 수 있다.
그래서 CAR는 단순 수용체가 아니라 **모듈식 세포공학 플랫폼**이다.

[해설]
==CAR==는 하나의 고정된 구조가 아니라 여러 기능 부품으로 나뉜 수용체이다.
==항원==결합부는 어떤 표적을 볼지 결정하고, hinge와 transmembrane domain은 수용체의 위치와 구조 안정성에 관여한다.
세포내 신호전달부는 표적을 만난 뒤 세포가 얼마나 강하게 활성화되고 얼마나 오래 지속될지를 결정한다.
따라서 ==CAR== 구조가 모듈식이라는 말은 표적성, 활성 강도, ==지속성==, ==안전성==을 설계자가 따로 조절할 수 있다는 뜻이다.

# 문제

scFv는 CAR에서 어떤 역할을 하며, 왜 CAR-X 치료제 연구에 자주 쓰이는가?

답:
scFv는 Variable Heavy와 Variable Light가 링커로 연결된 **단일 사슬 항체 단편**이다.
CAR의 항원 인식 부위로 작동한다.
항체의 특이성을 유지하면서도 작고 유전자 조작이 쉽다.

[해설]
==scFv==는 ==single-chain variable fragment==의 약자로, 항체의 ==항원== 결합 부위 중 ==heavy chain variable region==과 ==light chain variable region==을 링커로 연결한 작은 항체 조각이다.
항체 전체를 쓰지 않아도 ==항원==이 무엇인지 알아보는 특이성은 유지할 수 있다.
==CAR==에서는 ==scFv==가 세포 바깥쪽 ==항원== 인식 부위가 되어, ==CAR== 세포가 어떤 암 표적을 볼지 결정한다.
그래서 ==scFv==의 종류와 친화도는 ==CAR== 치료제의 표적성, 효능, ==안전성==에 직접 영향을 준다.

# 문제

1세대에서 4세대로 갈수록 CAR 구조는 단순한 공격 수용체에서 무엇으로 발전하는가?

답:
1세대: CD3ζ 단일 신호로 기본 공격만 가능
2세대: CD28 또는 4-1BB가 추가되어 활성과 지속성 개선
3세대: 공자극 도메인을 여러 개 결합
4세대: cytokine을 분비하는 armored CAR로 종양미세환경까지 조절

[해설]

2세대 ==CAR==는 ==CD28==이나 ==4-1BB== 같은 ==공자극 도메인==을 추가해 세포 활성과 ==지속성==을 보강했고, 현재 상용 ==CAR-T==의 핵심 구조가 되었다.

4세대 ==CAR==는 ==cytokine== 분비 같은 기능을 넣어 단순 살상 세포를 넘어 ==TME==까지 조절하는 armored ==CAR== 개념으로 확장된다.

# 문제

CD28, 4-1BB, IL-15는 CAR 설계에서 각각 어떤 의미로 이해해야 하는가?

답:
**CD28**: 빠르고 강한 초기 활성화
**4-1BB**: 장기 지속성과 memory phenotype 유지에 유리
**IL-15**: CAR-NK에서 생존과 증식에 매우 중요한 cytokine

[해설]
==CD28==과 ==4-1BB==는 ==CAR== 내부 신호전달부에 들어가는 **공자극 도메인**이다.
==공자극 도메인==은 ==CAR==가 ==항원==을 만났을 때 면역세포가 얼마나 빠르게 활성화되고 얼마나 오래 기능을 유지할지를 결정한다.
==CD28==은 빠르고 강한 초기 활성화를 유도하는 반면, ==4-1BB==는 상대적으로 장기 ==지속성==과 ==memory phenotype== 유지에 유리하다.
==IL-15==는 도메인이 아니라 ==cytokine==이며, ==CAR-NK==에서 ==NK cell==의 생존과 증식을 돕는 핵심 신호로 이해해야 한다.

# 문제

CAR-T는 혈액암에서 성공했는데 왜 고형암에서는 그대로 잘 안 되는가?

답:
**항원 이질성**과 antigen escape가 생긴다.
종양 안으로 **침투**하기 어렵다.
**TME**가 면역세포 기능을 억제한다.
세포 지속성이 떨어지고 CRS, ICANS 같은 독성 관리도 필요하다.

[해설]
==CAR-T==는 ==T cell==에 ==CAR==를 넣은 치료제로, ==혈액암==에서는 표적 암세포와 접촉하기 쉽고 CD19 같은 표적도 비교적 명확해 성공했다.
==고형암==은 암 덩어리 안으로 면역세포가 들어가야 하며, ==ECM==과 stromal barrier 때문에 침투가 어렵다.
또한 ==고형암==은 모든 암세포가 같은 ==항원==을 가지지 않아 ==antigen heterogeneity==와 ==antigen escape==가 생긴다.
여기에 ==TME==가 면역세포 기능을 억제하므로, ==CAR-T==가 ==혈액암==에서 성공한 논리를 ==고형암==에 그대로 적용하기 어렵다.

CAR-T와 CAR-NK를 치료제로 비교할 때, CAR-NK가 더 유리해 보이는 지점과 아직 해결해야 할 지점을 같이 쓰시오.

# 문제

T cell, NK cell, macrophage를 암 치료제용 면역세포로 볼 때 각각의 대표 강점은 무엇인가?

답:
T cell: **Expansion**
NK cell: **Safety**
Macrophage: **Infiltration**

[해설]

# 문제

Dual/Tandem CAR: 두 항원을 보게 해서 antigen escape를 줄임
AND gate: 두 항원이 함께 있을 때만 켜져 정상조직 공격을 줄임

하지만 지속성이 너무 강하면 만성 독성이나 정상 조직 공격 위험이 커진다.

[해설]
Persistence는 투여된 ==CAR== 세포가 체내에서 얼마나 오래 살아남아 기능을 유지하는지를 뜻한다.

# 문제

CAR-NK의 짧은 persistence는 왜 단점이면서도 반복 투여 전략의 근거가 될 수 있는가?

답:
짧은 persistence는 한 번 투여로 오래 유지되기 어렵다는 단점이다.
하지만 낮은 독성을 바탕으로 **반복 투여**가 가능하다는 장점으로 재해석될 수 있다.
장기 생존에만 의존하지 않고 여러 번 접근해 효과를 유지할 수 있다.

[해설]
==CAR-NK==는 ==CAR-T==에 비해 체내 ==지속성==이 짧은 경우가 많아, 한 번 투여로 장기간 효과를 유지하기 어렵다는 단점이 있다.
그러나 ==CAR-NK==는 상대적으로 독성이 낮고 ==off-the-shelf==로 준비할 가능성이 있어 ==반복 투여== 전략과 연결된다.
==반복 투여==는 짧은 ==지속성==을 여러 번의 투여로 보완해 치료 압력을 유지하려는 접근이다.
따라서 ==CAR-NK==의 짧은 ==persistence==는 단점이지만, 제품 설계에 따라 ==반복 투여== 가능한 장점으로도 해석될 수 있다.

항원 형태와 전달체 형태가 면역체계를 활성화시키는 방식을 결정한다.
생백신: 살아있는 바이러스 껍질 사용

==항원 형태==는 면역계에 무엇을 보여줄 것인지를 뜻하고, ==전달 방식==은 그 ==항원==을 어떤 형태로 몸 안에 넣을 것인지를 뜻한다.
==생백신==은 살아있는 약독화 병원체를 이용해 강한 ==면역반응==을 유도하는 방식이다.
==사백신==은 병원체를 죽인 뒤 사용하므로 증식 위험은 낮지만 ==면역반응==은 상대적으로 약할 수 있다.
==아단위 백신==은 병원체 전체가 아니라 특정 ==항원== 단백질만 정제해 보여주는 방식이다.
DNA/RNA 백신은 ==항원== 단백질 자체가 아니라 ==항원==을 만들 유전정보를 전달해 세포가 ==항원==을 만들게 하는 방식이다.

# 문제

COVID-19 mRNA vaccine이 감염백신의 새로운 기준으로 제시되는 이유는 무엇인가?

답:
mRNA vaccine은 공정과 효능에서 탁월함을 보였다.
**100/200일 project**로 next pandemic 대비 가능성을 제시했다.
대표 상용화 사례로 **Moderna**, **Pfizer**가 제시된다.

[해설]
COVID-19 ==mRNA vaccine==은 감염병 상황에서 mRNA 플랫폼이 실제 상용 백신으로 빠르게 작동할 수 있음을 보여준 사례이다.
mRNA 플랫폼은 ==항원== 설계 정보를 바꾸면 새로운 병원체에 맞춘 백신 후보를 비교적 빠르게 만들 수 있다.
자료에서 말하는 100/200일 project는 다음 팬데믹에서 백신 개발과 대응 시간을 크게 줄이려는 목표와 연결된다.
따라서 Moderna와 Pfizer 사례는 단순한 제품명 암기가 아니라, ==mRNA vaccine==이 공정과 효능 면에서 감염백신의 새로운 기준으로 제시된 근거이다.
