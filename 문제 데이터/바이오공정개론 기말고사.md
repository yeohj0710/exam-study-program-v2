# 문제
원핵생물 단백질 발현할 때 안정성과 거리가 먼 것은? (기출)

- 꼬리표(Tag)
- 샤페론
- 저온
- IPTG

답: ==IPTG==

[배경설명]
==원핵생물==은 세균 같은 단순한 세포이고, 재조합 단백질 발현은 세포 안에서 원하는 단백질을 만들게 하는 과정이다.
**단백질 안정성**은 단백질이 제대로 접히고, 잘 분해되지 않고, 기능을 유지하는지와 관련된다.
==꼬리표(Tag)==는 정제를 쉽게 하거나 일부 경우 용해도에 도움을 줄 수 있고, ==샤페론==은 단백질 접힘을 도와준다.
==저온==은 단백질이 천천히 만들어져 잘못 접히는 일을 줄일 수 있다.
==IPTG==는 발현을 켜는 ==유도물질==이다.
스위치를 켜는 역할이지 단백질 자체를 안정화하는 전략은 아니므로 안정성과 가장 거리가 멀다.

[보기해설]
O 꼬리표(Tag)
O 샤페론
O 저온
X ==IPTG== -> IPTG는 발현을 켜는 ==유도물질==이다. ==단백질 안정성== 자체를 높이는 전략은 아니다.

# 문제
효모(S. cerevisiae)를 단백질 생성에 사용할 때 장점이 아닌 것을 고르시오. (기출)

- 생화학, 유전학, 세포생물학 정보가 많이 알려져 모델 생물로 널리 쓰인다
- 비교적 단순한 배지에서 높은 세포 밀도까지 빠르게 자랄 수 있다
- 강한 발현 촉진 부위(promoter)와 2 μm 플라스미드(plasmid)를 발현 벡터 시스템에 활용할 수 있다
- 별도 유전공학적 개량(engineering) 없이 사람형 N-당쇄화(N-glycosylation)을 그대로 완성한다

답: 별도 ==유전공학적 개량(engineering)== 없이 사람형 ==N-당쇄화(N-glycosylation)==을 그대로 완성한다

[배경설명]
**효모(S. cerevisiae)**는 빵이나 맥주에 쓰이는 **효모**로, 세균보다 사람 세포에 조금 더 가까운 **진핵생물**이다.
그래서 세균보다 복잡한 단백질을 만들기 좋고, 연구가 많이 되어 있으며, 빨리 자란다.
강한 **발현 촉진 부위(promoter)**와 **플라스미드(plasmid)** 시스템을 활용할 수 있다는 점도 장점이다.
하지만 **당쇄**, 즉 **당쇄화(glycosylation)**은 사람 세포와 완전히 같지 않다.
사람형 **N-당쇄화(N-glycosylation)**을 그대로 만들려면 보통 별도 **유전공학적 개량(engineering)**이 필요하다.
따라서 "별도 **유전공학적 개량(engineering)** 없이 사람형 **당쇄**를 그대로 완성한다"는 설명은 장점이 아니라 틀린 설명이다.

[보기해설]
O 생화학, 유전학, 세포생물학 정보가 많이 알려져 모델 생물로 널리 쓰인다
O 비교적 단순한 배지에서 높은 세포 밀도까지 빠르게 자랄 수 있다
O 강한 발현 촉진 부위(promoter)와 2 μm 플라스미드(plasmid)를 발현 벡터 시스템에 활용할 수 있다
X 별도 유전공학적 개량(engineering) 없이 사람형 N-당쇄화(N-glycosylation)을 그대로 완성한다 -> 효모 당쇄는 사람형과 다를 수 있어 ==사람형 당쇄화 개량(humanized glycosylation engineering)==이 필요할 수 있다.

# 문제
아이솔레이터(Isolator)에 대한 설명으로 옳지 않은 것은? (기출)

- 에어락(Airlock)과 장갑(glove)을 이용해 작업자와 작업 챔버를 물리적으로 분리한다
- 헤파 여과(HEPA filtration)와 세척 가능한 표면으로 오염 관리에 유리하다
- 필요에 따라 음압 모드(negative pressure mode)를 적용할 수 있다
- 작업 중 문(door)을 열어 작업자가 핵심 무균구역(critical zone)에 직접 손을 넣는 방식이 기본이다

답: 작업 중 ==문(door)==를 열어 작업자가 ==핵심 무균구역(critical zone)==에 직접 손을 넣는 방식이 기본이다

[배경설명]
**아이솔레이터(Isolator)**는 말 그대로 제품이 있는 중요한 작업 공간을 바깥과 격리하는 장치이다.
**작업자**는 문을 열고 손을 직접 넣는 것이 아니라,
==장갑(glove)==, ==에어락(airlock)==, 헤파 필터 공기(HEPA-filtered air) 같은 장치를 통해 오염을 막으며 작업한다.
핵심 무균구역(Critical zone)은 제품이 노출되는 가장 중요한 무균 구역이다.
그래서 작업 중 문을 열고 직접 손을 넣는 방식은 아이솔레이터(isolator)의 기본 개념과 반대이다.
음압 모드(Negative pressure mode)는 독성 물질이나 생물학적 위험 물질이 밖으로 새지 않게 할 때 쓰일 수 있다.

[보기해설]
O 에어락(Airlock)과 장갑(glove)을 이용해 작업자와 작업 챔버를 물리적으로 분리한다
O 헤파 여과(HEPA filtration)와 세척 가능한 표면으로 오염 관리에 유리하다
O 필요에 따라 음압 모드(negative pressure mode)를 적용할 수 있다
X 작업 중 문(door)을 열어 작업자가 핵심 무균구역(critical zone)에 직접 손을 넣는 방식이 기본이다 -> 아이솔레이터(isolator)는 문(door) open 직접 작업이 아니라 ==장갑(glove)==와 ==에어락(airlock)==으로 격리 작업을 한다.

# 문제
항체의약품-표적-질병 연결로 잘못된 것은? (기출)

- 베바시주맙(Bevacizumab, Avastin)은 혈관내피성장인자(VEGF)를 막아 종양의 혈관 생성을 억제하는 항체의약품이다
- 옵디보(Opdivo, nivolumab)는 PD-1을 막아 T 세포의 항암 면역 반응을 다시 살리는 면역관문억제제이다
- 허셉틴(Herceptin, trastuzumab)은 HER2 양성 유방암 등에서 HER2를 표적으로 한다
- 베바시주맙(Bevacizumab)은 PD-1을 막아 T 세포 항암 면역을 직접 재활성화하는 약물이다

답: ==베바시주맙(Bevacizumab)은 PD-1을 막아 T 세포 항암 면역을 직접 재활성화하는 약물이다==

[배경설명]
이 문제는 항체의약품 이름, 표적, 질병 또는 작용전략을 짝짓는 문제이다.
**베바시주맙(Bevacizumab, Avastin)**은 **VEGF**를 막는다. VEGF는 종양이 새 혈관을 만들도록 돕는 신호라서, 베바시주맙은 **혈관생성 억제** 쪽으로 이해하면 된다.
**옵디보(Opdivo, nivolumab)**는 **PD-1**을 막는 면역관문억제제이다. T 세포가 암세포를 다시 공격하도록 도와주는 쪽이다.
**허셉틴(Herceptin, trastuzumab)**은 **HER2**를 표적으로 하는 항체의약품이다.
따라서 베바시주맙을 PD-1 면역관문억제제로 설명한 보기가 잘못된 연결이다. PD-1 쪽은 옵디보나 키트루다 계열로 잡으면 된다.

암기표:
- 베바시주맙(Bevacizumab, Avastin): VEGF 억제 -> 종양 혈관생성 억제
- 옵디보(Opdivo, nivolumab): PD-1 억제 -> T 세포 항암 면역 재활성화
- 키트루다(Keytruda, pembrolizumab): PD-1 억제 -> T 세포 항암 면역 재활성화
- 허셉틴(Herceptin, trastuzumab): HER2 표적 -> HER2 양성 유방암 등
- 휴미라(Humira, adalimumab): TNF-α 억제 -> 류마티스 관절염 같은 자가면역질환

[보기해설]
O 베바시주맙(Bevacizumab, Avastin)은 혈관내피성장인자(VEGF)를 막아 종양의 혈관 생성을 억제하는 항체의약품이다
O 옵디보(Opdivo, nivolumab)는 PD-1을 막아 T 세포의 항암 면역 반응을 다시 살리는 면역관문억제제이다
O 허셉틴(Herceptin, trastuzumab)은 HER2 양성 유방암 등에서 HER2를 표적으로 한다
X 베바시주맙(Bevacizumab)은 PD-1을 막아 T 세포 항암 면역을 직접 재활성화하는 약물이다 -> 베바시주맙은 VEGF 억제, 옵디보는 PD-1 억제이다.

# 문제
완제품 제출 또는 배치 방출 관련 GMP 문서 설명으로 옳지 않은 것은? (기출)

- 시험기록서, 제조지시 및 기록서, 포장지시 및 기록서는 품질기록서(Quality Record)에 속한다
- 제품표준서는 동일한 수준의 제조와 품질관리를 위해 제조 및 품질관리 내용을 표준화한 문서이다
- QA는 제조, 포장, 출하, 시판 후 불만사항까지 제품 전주기를 관리한다
- 비통제문서만 있으면 시험기록서와 제조기록서를 대체해 완제품 방출 근거로 충분하다

답: ==비통제문서==만 있으면 ==시험기록서==와 ==제조기록서==를 대체해 ==완제품 방출== 근거로 충분하다

[배경설명]
**GMP**는 의약품을 항상 같은 품질로 만들기 위한 규칙이다.
그래서 "기억"이나 "대충 적은 문서"가 아니라 **통제된 공식 문서**와 기록이 필요하다.
**시험기록서**, **제조기록서**, **포장기록서**, **제품표준서** 같은 문서는 배치가 제대로 만들어졌는지 판단하는 근거가 된다.
**비통제문서**는 최신본인지, 승인된 내용인지, 누가 바꿨는지 추적하기 어렵다. 그래서 완제품 방출 근거를 대체할 수 없다.
이 문항은 문서 이름을 모두 외우기보다 "**GMP**에서는 공식 기록이 제품 방출의 근거"라는 원리를 잡으면 된다.

[보기해설]
O 시험기록서, 제조지시 및 기록서, 포장지시 및 기록서는 품질기록서(Quality Record)에 속한다
O 제품표준서는 동일한 수준의 제조와 품질관리를 위해 제조 및 품질관리 내용을 표준화한 문서이다
O QA는 제조, 포장, 출하, 시판 후 불만사항까지 제품 전주기를 관리한다
X 비통제문서만 있으면 시험기록서와 제조기록서를 대체해 완제품 방출 근거로 충분하다 -> 완제품 방출은 통제된 GMP 문서와 공식 기록을 근거로 해야 한다.

# 문제
QC의 목표가 아닌 것은? (기출)

- 품질(Quality)
- 안전성(Safety)
- 유효성(Efficacy)
- 여러 분야 협업(Multidisciplinary)

답: ==여러 분야 협업(Multidisciplinary)==

[배경설명]
**QC**는 품질관리(Quality Control)이다.
**바이오의약품**에서 **QC**의 핵심 목표는 제품이 품질, 안전성, 유효성을 만족하는지 확인하는 것이다.
품질(Quality)는 제품이 기준에 맞는지 보는 것이다.
안전성(Safety)는 환자에게 위험한 오염이나 불순물이 없는지 보는 것이다.
유효성(Efficacy)는 약효와 연결되는 특성이 유지되는지를 뜻한다.
같은 슬라이드의 분석 시험(analytical testing) 중요성은 이 목표를 실제 시험으로 확인하는 용도이다.
반드시 같이 볼 항목은 다음이다.
==공정 중 시험(process testing)==,
==출하 전 품질 시험(lot release testing)==,
==사용기간 설정을 위한 안정성 시험(stability test)==,
**환자 안전성**이다.
==여러 분야 협업(Multidisciplinary)==는 여러 분야가 함께 관여한다는 뜻이지 **QC**의 직접 목표가 아니다.

[보기해설]
O 품질(Quality)
O 안전성(Safety)
O 유효성(Efficacy)
X 여러 분야 협업(Multidisciplinary) -> 여러 분야 협업(Multidisciplinary)는 여러 분야가 함께 관여한다는 뜻이지 QC의 직접 목표가 아니다.

# 문제
무균공정(Aseptic processing)에서 환경 모니터링(EM)이 중요한 이유와 구성 요소를 작성하시오. (기출)

답:
이유: 무균공정에서는 제품을 마지막에 강하게 멸균하기 어렵기 때문에, 제조 환경의 오염 여부를 계속 확인해야 한다. 기준 이상 미생물이 나오면 어떤 균인지 확인하고, 어디서 들어왔는지 찾아 조치해야 한다.

구성 요소(자료 기준):
**부유입자 모니터링**: 공기 중 떠다니는 먼지/입자 확인
**부유균 모니터링**: 공기 중 떠다니는 살아 있는 미생물 확인
**낙하균 모니터링**: 공기 중에서 떨어져 내려앉는 미생물 확인
**표면균 모니터링**: 작업대나 장비 표면에 묻은 미생물 확인

[배경설명]
==무균공정(Aseptic processing)==은 제품을 마지막에 세게 멸균하기 어려운 상황에서 쓰인다.
제조 중 오염이 들어오지 않게 관리하는 방식이다.
EM은 ==환경 모니터링(Environmental Monitoring)==, 즉 작업 **환경**을 계속 감시하는 것이다.
무균공정에서는 눈에 보이지 않는 작은 먼지나 미생물이 제품을 오염시킬 수 있다.

==부유입자==는 공기 중 떠다니는 먼지/입자이고,
==부유균==은 공기 중 떠다니는 살아 있는 미생물이다.
==낙하균==은 공기 중에 있다가 바닥이나 배지 위로 떨어지는 미생물이고,
==표면균==은 작업대나 장비 표면에 묻은 미생물이다.
자료 표에는 작업자 샘플링, 특히 장갑/가운 검사도 나오므로, 여유가 있으면 같이 적으면 좋다.
암기: EM = **부유입자, 부유균, 낙하균, 표면균**을 보는 ==제조환경 오염 감시==.

분석법(Analytical method)이 왜 중요한지 설명하시오. (기출)

답: 제품의 **품질(quality), 안전성(safety), 유효성(efficacy)**를 객관적으로 확인하기 위해 필요하다

정확한지, 반복하면 비슷한 값이 나오는지 같은 밸리데이션(validation)도 필요하다.

# 문제
항체 의약품 개발에서 단일 표적(single target) 대신 여러 단백질 표적(target)에 결합하는 약물을 개발했으나 임상에서 유효한 결과가 나오지 않았다. 이때 취할 수 있는 전략을 쓰시오. (기출)

답: **표적(target) 조합이 질병 기전과 맞는지 재검토**한다.
**생체표지자(biomarker)** 또는 정밀 환자 선별 분석으로 반응할 환자군을 다시 정한다.
실패 원인을 **물질, 장비, 방법, 사람, 환경(5M)** 관점에서 분석한다.
결과에 따라 표적 조합을 줄이거나 바꾸고, 필요하면 **단일 표적 전략, 병용요법, 다른 항체 전략**으로 재설계한다.

[배경설명]
단일 표적(single target)은 한 표적만 노리는 전략이고, 다중 표적(multi-target)은 여러 표적을 동시에 노리는 전략이다.

임상에서 실패했다면 먼저 "이 표적 조합이 실제 질병을 움직이는 핵심인가?"를 다시 봐야 한다.

# 문제
바이오의약품 QC에서 핵심품질특성(CQA)과 영향 설명으로 옳은 것을 모두 고르시오.

- 당쇄화(Glycosylation)는 몸 밖 제거 속도(clearance)와 반감기(half-life)에 영향을 줄 수 있다
- 응집(Aggregation)은 안정성 문제와 면역반응 위험(immunogenicity risk)으로 이어질 수 있다
- 전하 변이체(Charge variants)는 PK 변화와 연결될 수 있다
- 숙주세포단백질(HCP)/DNA 잔류 확인은 안전성(safety) 확보와 관련된다
- 핵심품질특성(CQA)은 제품 색깔만 의미하므로 유효성(efficacy)이나 안전성(safety)과는 관련이 없다

답: 당쇄화(Glycosylation)는 ==몸 밖 제거 속도(clearance)==와 반감기(half-life)에 영향을 줄 수 있다
응집(Aggregation)은 안정성 문제와 ==면역반응 위험(immunogenicity risk)==로 이어질 수 있다

숙주세포단백질(HCP)/DNA 잔류 확인은 안전성(safety) 확보와 관련된다

[배경설명]
==핵심품질특성(CQA)==는 **중요 품질 특성(Critical Quality Attribute)**, 즉 제품의 품질을 좌우하는 중요한 특성이다.
**당쇄화(Glycosylation)**은 단백질에 붙은 당 구조이고, 몸에서 얼마나 빨리 제거되는지나 반감기에 영향을 줄 수 있다.
**응집(Aggregation)**은 단백질끼리 뭉치는 현상이라 안정성을 떨어뜨리고 면역반응 위험을 높일 수 있다.
전하 변이체(Charge variants)는 같은 단백질이라도 전하가 달라진 형태이고, ==PK==나 활성에 영향을 줄 수 있다.
**숙주세포단백질(HCP)**는 생산세포에서 나온 단백질 불순물, DNA 잔류물은 생산세포에서 온 불순물이므로 **안전성(safety)**와 연결된다.

[보기해설]
O 당쇄화(Glycosylation)는 몸 밖 제거 속도(clearance)와 반감기(half-life)에 영향을 줄 수 있다
O 응집(Aggregation)은 안정성 문제와 면역반응 위험(immunogenicity risk)으로 이어질 수 있다
O 전하 변이체(Charge variants)는 PK 변화와 연결될 수 있다
O 숙주세포단백질(HCP)/DNA 잔류 확인은 안전성(safety) 확보와 관련된다
X ==핵심품질특성(CQA)==는 제품 색깔만 의미하므로 유효성(efficacy)이나 안전성(safety)과는 관련이 없다 -> ==핵심품질특성(CQA)==는 품질·안전성·유효성에 영향을 주는 중요한 품질 특성이다.

- 일탈(Deviation)은 승인된 지시서나 정해진 기준(established standard)에서 벗어난 상태이다
- 시정예방조치(CAPA)는 시정조치(corrective action)과 예방조치(preventive action)을 세우고 효과를 확인하는 체계이다
- 중요한 품질 문제는 원인, 조치, 효과 확인까지 문서화되어야 한다
- 시정예방조치(CAPA)는 문제가 재발해도 원인 분석 없이 문서만 닫는 절차이다

답: ==일탈(Deviation)==은 승인된 지시서나 ==정해진 기준(established standard)==에서 벗어난 상태이다

중요한 품질 문제는 원인, 조치, 효과 확인까지 문서화되어야 한다

[배경설명]
==일탈(Deviation)==은 정해진 절차나 기준에서 벗어난 일이다.
예를 들어 표준작업절차서(SOP)와 다르게 작업했거나 기준 밖 결과가 나온 경우이다.
**시정예방조치(CAPA)**는 문제를 그냥 덮는 문서가 아니다.
이미 생긴 문제를 고치는 ==시정조치(corrective action)==과,
다시 생기지 않게 막는 ==예방조치(preventive action)==을 포함한다.
중요한 것은 원인 분석, 조치, 효과 확인이다. 효과 확인이 없으면 같은 문제가 반복될 수 있다.
그래서 **시정예방조치(CAPA)**를 원인 분석 없이 문서만 닫는 절차라고 보는 것은 틀리다.

# 문제
환경 모니터링(Environmental Monitoring) 표의 ISO 등급과 GMP 등급(grade) 연결로 옳은 것을 모두 고르시오.

- ISO 5는 GMP Grade A 또는 GMP Grade B 비작업 상태(at rest)와 연결된다
- ISO 7은 GMP Grade B 작업 중(in operation) 또는 GMP Grade C 비작업 상태(at rest)와 연결된다
- ISO 8은 GMP Grade C 작업 중(in operation) 또는 GMP Grade D 비작업 상태(at rest)와 연결된다
- ISO 등급 숫자가 낮을수록 더 깨끗한 영역이다
- ISO 8이 ISO 5보다 더 중요하고 엄격한(critical) 무균 영역이다

ISO 8은 GMP Grade C 작업 중(in operation) 또는 GMP Grade D 비작업 상태(at rest)와 연결된다
ISO 등급 숫자가 낮을수록 더 깨끗한 영역이다

[배경설명]
==환경 모니터링(Environmental Monitoring)==에서 **ISO** 숫자는 공기 중 입자 수와 관련된 ==청정도== 등급이다.
숫자가 낮을수록 더 깨끗하고 더 중요하고 엄격한(critical) 구역이다. 그래서 **ISO** 5가 **ISO** 8보다 훨씬 더 엄격하다.
**GMP Grade A**는 가장 중요한 무균 작업 영역이다.
GMP Grade가 내려갈수록 덜 중요하고 엄격한(critical) 영역으로 이해하면 된다.
표 문제는 숫자를 전부 외우기보다 "**ISO** 숫자 낮음 = 더 깨끗함 = 더 중요하고 엄격함(critical)"이라는 방향을 먼저 잡아야 한다.
